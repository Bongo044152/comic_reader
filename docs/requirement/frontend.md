# 前端功能

> `dev.md` 第 3 章的附屬文件。第 1 章是總覽，先讀完它再看後面的功能卡。
>
> 資料的定義見 [data.md](data.md)。API 的路徑與格式在 [api.md](api.md)，這裡只描述前端與後端「各做什麼」，不寫 API 細節。

## 1. 總覽

### 1.1 前端的角色與邊界

前端負責呈現畫面、頁面導覽、基本的輸入檢查，以及只存在於畫面的暫時狀態（例如目前的閱讀方式）。

- 前端只經由 Backend 的 REST API 取得資料，不直接存取資料庫、檔案系統或 plugin。
- 業務邏輯在後端：權限檢查、唯一性、ref count、快取與圖片抓取。前端的檢查只是為了即時回饋，不能取代後端的檢查。
- V1 以電腦為對象（A-11）。

### 1.4 共通行為

這些行為適用所有功能，功能卡的「失敗」欄只列各功能特有的錯誤，登入過期（401）與伺服器錯誤（5xx）不再重複。

| 行為 | 說明 |
| --- | --- |
| 載入動畫（UN-7） | 等待網路請求（漫畫詳情、章節圖片、搜尋結果）時顯示，讓使用者知道系統正在處理 |
| 登入過期 | 登入以外的 API 回 401，導回登入頁（登入 API 的 401 代表登入失敗） |
| 錯誤提示（UN-8） | 依錯誤的類型決定顯示方式，見 1.5 |
| 404 頁面（UN-9） | 頁面或資源不存在時顯示，附回到主頁的連結 |

### 1.5 錯誤分類

依「錯在哪」分成三類，各自決定顯示方式。

| 類型 | 例子 | 顯示方式 |
| --- | --- | --- |
| 來源端 | 同步失敗、被來源封鎖、網站改版（PL-07）、漫畫下架 | 與畫面元素綁在一起，類似新聞網站刷新失敗 |
| 使用者端 | 操作不合法、手動檢查更新太頻繁（C-4） | 即時回饋，形式看設計（例如彈跳視窗） |
| 伺服器 | 後端內部錯誤 | 回傳 5xx；前端顯示通用紅色提示（UN-8），後端記入 log |

### 1.6 功能卡欄位

| 欄位 | 內容 |
| --- | --- |
| 功能名稱 | 一句話說明做什麼 |
| 邊界 | 做什麼、不做什麼 |
| 觸發 | 誰、在什麼情況下啟動 |
| 輸入 | 參數與格式、必填或選填 |
| 輸出 | 成功時回傳什麼、畫面怎麼變 |
| 資料 | 讀寫哪些資料 |
| 動作 | 具體步驟，依序列出 |
| 權限 | 誰能用；是否影響資料可見範圍 |
| 失敗 | 什麼操作引起什麼錯誤、屬於哪一類（見 1.5）、系統怎麼反應 |
| 前後端分工 | 驗證、計算、狀態分別放哪一邊 |
| 規模 | 資料量、分頁、逾時、並發 |
| NOTE | 選填。特殊行為與補充 |

## 2. 登入

### F-01 登入、登出

**功能名稱**：以帳號密碼登入系統，並可登出。

**邊界**
- 做：帳號密碼登入、登出。
- 不做：註冊、忘記密碼、修改密碼。帳號由管理者經 Backend Management 建立（A-13）。

**觸發**：使用者在登入頁送出表單；使用者按登出；任何 API 回 401。

**輸入**：`username`、`password`，皆必填。

**輸出**：登入成功 Jump 主頁；失敗留在登入頁並顯示登入失敗。登出後回登入頁。

**資料**：讀 [User](data.md#user)（由後端驗證）；建立或清除 [登入狀態](data.md#草稿-登入狀態)。

**動作**
1. 送出帳號與密碼。
2. 後端驗證，成功則建立登入狀態。
3. 前端 Jump 主頁。登出則清除登入狀態並 Jump 登入頁。

**權限**：任何人都能開登入頁，其餘頁面都需要登入。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 送出登入表單 | 帳號或密碼為空 | 使用者端 | 前端擋下，提示輸入 |
| 送出登入表單 | 帳號不存在或密碼錯誤 | 使用者端 | 統一顯示「登入失敗」，避免洩漏帳號是否存在 |

**前後端分工**：前端做空值檢查與導覽；後端做驗證、建立與清除登入狀態。

**規模**：單次請求，無特別限制。

## 3. 搜尋與加入

### F-02 本地搜尋

**功能名稱**：以標題搜尋自己書庫中的漫畫。

**邊界**
- 做：只搜書庫，以標題比對。
- 不做：搜尋來源網站（見 [F-03](#f-03-plugin-搜尋)）、依作者或標籤搜尋。

**觸發**：使用者在主頁的搜尋框送出關鍵字。

**輸入**：關鍵字，必填。

**輸出**：書庫中符合的漫畫列表（封面、標題）；沒有符合時顯示無結果；點擊 Jump 漫畫詳情頁。

**資料**：讀 [Manga](data.md#manga)，範圍限制在使用者書庫的 [FolderManga](data.md#foldermanga)。

**動作**
1. 送出關鍵字。
2. 後端在使用者的書庫中以標題比對。
3. 前端 Render 搜尋結果。

**權限**：已登入；只搜自己的書庫。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 送出關鍵字 | 關鍵字為空 | 使用者端 | 前端攔截，不送出請求 |

**前後端分工**：前端收集輸入、顯示結果；後端比對。

**規模**：範圍是單一使用者的書庫，V1 不分頁。

### F-03 plugin 搜尋

**功能名稱**：勾選要搜的 plugin，向來源網站搜尋漫畫。

**邊界**
- 做：勾選 plugin（全選即全域）、顯示合併後的結果、標示是否已在書庫、結果可進詳情頁並加入書庫。
- 不做：把搜尋結果寫入資料庫（只有「加入」才寫入）、plugin 的安裝與管理（由 Backend Management 負責）。

**觸發**：使用者在主頁勾選 plugin 並送出關鍵字。

**輸入**：關鍵字；勾選的 plugin（一個以上）。

**輸出**：合併後的漫畫列表（來源、標題、封面、是否已在書庫）；部分 plugin 失敗時列出失敗的來源。

**資料**：讀 [Plugin registry](data.md#草稿-plugin-registry)（經 API 取得 plugin 清單）。搜尋結果不寫入資料庫。

**動作**
1. 前端取得已註冊的 plugin 清單供勾選。
2. 送出關鍵字與勾選結果。
3. 後端並行轉呼叫各 plugin 並合併。
4. 前端顯示結果；點擊進入漫畫詳情頁（[F-10](#f-10-漫畫詳情)）。

**權限**：已登入。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 送出搜尋 | 沒有勾選任何 plugin | 使用者端 | 前端擋下，提示勾選 |
| 送出搜尋 | 單一 plugin 失敗或逾時 | 來源端 | 不影響其他 plugin，在畫面標示失敗的來源 |
| 送出搜尋 | 全部 plugin 失敗 | 來源端 | 與畫面元素綁在一起顯示 |

**前後端分工**：前端做勾選介面、顯示結果與失敗來源；後端做並行呼叫、合併、判斷是否已在書庫。

**規模**：plugin 約 10 個以內；等待時顯示載入動畫；逾時值待定（Q-F6）。

### F-04 加入書庫

**功能名稱**：把一部漫畫加入自己的書庫。

**邊界**
- 做：建立使用者與這部漫畫的關聯（放進書庫）。
- 不做：抓取詳情與章節（見 [F-11](#f-11-同步詳情)、[F-12](#f-12-同步章節)，成本不同，分開處理）；選擇資料夾（見 [F-08](#f-08-加入移出資料夾)）。

**觸發**：使用者在漫畫詳情頁按「加入」。

**輸入**：漫畫識別（來源與來源上的 ID）、標題、封面（來自搜尋結果）。

**輸出**：成功後按鈕狀態改變，詳情頁出現移除與加入資料夾的入口。

**資料**：寫 [FolderManga](data.md#foldermanga)（書庫）；漫畫不在資料庫時，後端同時建立 [Manga](data.md#manga)。

**動作**
1. 使用者按加入。
2. 後端建立關聯（必要時先建立 Manga）。
3. 前端小範圍 Render，更新按鈕狀態。

**權限**：已登入。

**失敗**：沒有特有的錯誤。已加入時重複按不報錯（冪等）。

**前後端分工**：前端更新按鈕狀態；後端建立 Manga 與關聯、處理重複。

**規模**：單次操作。

**NOTE**：加入之後，同步詳情與同步章節的結果才會寫入資料庫。

## 4. 書庫與資料夾

### F-05 書庫列表

**功能名稱**：顯示自己書庫中的漫畫，也就是主頁的漫畫列表。

**邊界**
- 做：列出書庫中的漫畫（封面、標題、最新話）、點擊進詳情頁、移除漫畫（見 [F-09](#f-09-移除漫畫)）。
- 不做：依資料夾篩選（由資料夾頁面提供，見 [F-06](#f-06-資料夾管理)、[F-07](#f-07-資料夾內文)）。

**觸發**：進入主頁。

**輸入**：無，以目前登入者為準。

**輸出**：書庫的漫畫列表；書庫為空時顯示空列表的提示。

**資料**：讀 [Folder](data.md#folder)（書庫）、[FolderManga](data.md#foldermanga)、[Manga](data.md#manga)；最新話來自 [Chapter](data.md#chapter)。

**動作**
1. 進入主頁時載入書庫列表。
2. 前端 Render；點擊漫畫 Jump 漫畫詳情頁。

**權限**：已登入；只看得到自己的書庫。

**失敗**：沒有特有的錯誤。

**前後端分工**：前端顯示；後端組出列表（含最新話）。

**規模**：整個書庫一次載入，V1 不分頁。

**NOTE**：與資料夾內文（[F-07](#f-07-資料夾內文)）共用同一個列表元件，書庫就是預設資料夾 `library`。

### F-06 資料夾管理

**功能名稱**：建立、重新命名、刪除自訂資料夾。

**邊界**
- 做：自訂資料夾的建立、重新命名、刪除；顯示資料夾列表，書庫排第一。
- 不做：刪除或重新命名書庫；刪除資料夾時不影響漫畫本身與書庫。

**觸發**：使用者從主頁的資料夾入口進入資料夾頁面，並在頁面上操作。

**輸入**：資料夾名稱（建立、重新命名時必填，同一位使用者內不可重複）。

**輸出**：更新後的資料夾列表；點擊資料夾 Jump 資料夾內文。

**資料**：讀寫 [Folder](data.md#folder)；刪除時連帶刪除該資料夾的 [FolderManga](data.md#foldermanga)。

**動作**
1. 載入資料夾列表。
2. 建立、重新命名或刪除。
3. Render 更新後的列表。

**權限**：已登入；只能操作自己的資料夾。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 建立、重新命名資料夾 | 名稱為空 | 使用者端 | 前端擋下 |
| 建立、重新命名資料夾 | 名稱與同一位使用者的其他資料夾重複 | 使用者端 | 即時回饋名稱重複 |
| 刪除、重新命名書庫 | 書庫不可刪除、不可重新命名 | 使用者端 | 前端不提供這兩個按鈕，後端也拒絕 |
| 操作資料夾 | 資料夾不存在或不屬於該使用者 | 使用者端 | 顯示 404 頁面 |

**前後端分工**：前端做空值檢查、隱藏書庫的刪除與重新命名；後端做唯一性、書庫保護、權限檢查。

**規模**：自訂資料夾數量沒有上限，V1 不分頁。

### F-07 資料夾內文

**功能名稱**：瀏覽某個資料夾內的漫畫。

**邊界**
- 做：列出資料夾成員、進詳情頁、移出資料夾（見 [F-08](#f-08-加入移出資料夾)）。
- 不做：編輯漫畫資訊。

**觸發**：在資料夾頁面點擊資料夾。

**輸入**：資料夾。

**輸出**：該資料夾內的漫畫列表。

**資料**：讀 [FolderManga](data.md#foldermanga)、[Manga](data.md#manga)、[Chapter](data.md#chapter)。

**動作**
1. 載入資料夾成員。
2. Render；點擊漫畫 Jump 漫畫詳情頁。

**權限**：已登入；只能看自己的資料夾。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 進入資料夾內文 | 資料夾不存在或不屬於該使用者 | 使用者端 | 顯示 404 頁面 |
| 點擊資料夾內的漫畫進入詳情頁 | 漫畫已被移除 | 使用者端 | 顯示 404 頁面 |

**前後端分工**：同 [F-05](#f-05-書庫列表)。

**規模**：同 [F-05](#f-05-書庫列表)。

**NOTE**：自訂資料夾中的「移除」是移出資料夾（[F-08](#f-08-加入移出資料夾)）；在書庫中則是真正的刪除（[F-09](#f-09-移除漫畫)）。

### F-08 加入、移出資料夾

**功能名稱**：把書庫中的漫畫放進自訂資料夾，或從資料夾移出。

**邊界**
- 做：一部漫畫可放進多個資料夾（C-1）；選擇已有的資料夾，或輸入新名稱同時建立資料夾並加入。
- 不做：複製漫畫資料（資料夾只存關係）；未加入書庫的漫畫不能放進資料夾。

**觸發**：使用者在詳情頁按「加入資料夾」，或在資料夾內文按移出。

**輸入**：漫畫；資料夾（已有的資料夾，或新名稱）。

**輸出**：成功後更新顯示（詳情頁所屬的資料夾、資料夾內文列表）。

**資料**：寫或刪 [FolderManga](data.md#foldermanga)；輸入新名稱時另寫 [Folder](data.md#folder)。

**動作**
1. 加入：選資料夾（或輸入新名稱）後送出。
2. 移出：在資料夾內文按移出。
3. 前端更新顯示。

**權限**：已登入；只能操作自己的資料夾與書庫。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 加入資料夾 | 漫畫尚未加入書庫 | 使用者端 | 前端停用這個動作，後端也拒絕 |
| 加入、移出資料夾 | 資料夾不存在或不屬於該使用者 | 使用者端 | 即時回饋 |
| 輸入新名稱 | 名稱為空或與其他資料夾重複 | 使用者端 | 即時回饋 |
| 移出資料夾 | 漫畫已不在這個資料夾 | 使用者端 | 即時回饋 |

**前後端分工**：前端在未加入書庫時停用按鈕；後端檢查書庫前提與唯一性，建立資料夾與加入關係一起成功或一起失敗。

**規模**：單次操作。

### F-09 移除漫畫

**功能名稱**：從書庫移除漫畫，等於真正刪除這部漫畫。

**邊界**
- 做：移除自己書庫中的漫畫，連帶移除其他資料夾中的這部漫畫。
- 不做：影響其他使用者的書庫；立即刪除共用的漫畫資料與圖片（資料以 ref count 歸零才回收，圖片留給淘汰清理）。

**觸發**：使用者在主頁的書庫列表或漫畫詳情頁按移除。

**輸入**：漫畫。

**輸出**：書庫列表移除該筆；在詳情頁操作則 Jump 回前一頁，前一頁的列表要反映已移除，不能顯示舊資料。

**資料**：刪 [FolderManga](data.md#foldermanga)（書庫與其他資料夾）；ref count 歸零時後端刪除 [Manga](data.md#manga) 與 [Chapter](data.md#chapter)。

**動作**
1. 使用者按移除。
2. 後端移除使用者的書庫關係並連動其他資料夾，必要時回收共用資料。
3. 前端更新列表或回前一頁。

**權限**：已登入；只能移除自己的。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 移除漫畫 | 這部漫畫已不在書庫 | 使用者端 | 顯示 404 頁面 |

**前後端分工**：前端更新列表與導覽；後端做連動移除與 ref count。

**規模**：單次操作。

**NOTE**：只有漫畫已在書庫時才顯示移除按鈕。是否需要二次確認待定（Q-F9）。

## 5. 漫畫詳情與同步

### F-10 漫畫詳情

**功能名稱**：顯示一部漫畫的詳情與章節列表，是同步與閱讀的入口。

**邊界**
- 做：顯示詳情（來源沒有的欄位顯示「未知」）與章節列表；依狀態提供加入、移除、加入資料夾、同步、進入閱讀的入口。
- 不做：編輯詳情。

**觸發**：從書庫列表、資料夾內文、本地搜尋或 plugin 搜尋結果點擊進入。

**輸入**：漫畫識別。資料庫已有的用資料庫 id；可能還不在資料庫的（plugin 搜尋結果）用來源與來源上的 ID。

**輸出**：詳情與章節列表；按鈕依狀態顯示：已加入顯示移除與加入資料夾，未加入顯示加入。

**資料**：讀 [Manga](data.md#manga)、[Chapter](data.md#chapter)、[FolderManga](data.md#foldermanga)（是否已加入、所屬資料夾）。

**動作**
1. 以漫畫識別查詢本地。
2. 本地有：顯示本地詳情與章節列表；章節列表有內容，表示資料庫有這個章節的內容。
3. 本地沒有（來自 plugin 搜尋）：向遠端取詳情顯示，不寫入資料庫，章節列表為空。
4. 點擊章節 Jump 閱讀器頁面（[F-13](#f-13-閱讀章節)）。

**權限**：已登入。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 進入詳情頁 | 本地沒有這部漫畫，且不是從搜尋進入 | 使用者端 | 顯示 404 頁面 |
| 從 plugin 搜尋結果進入詳情頁 | 向遠端取詳情失敗 | 來源端 | 與畫面元素綁在一起顯示 |

**前後端分工**：前端依狀態決定按鈕與區塊；後端查詢與組合。

**規模**：章節列表一次載入完整的本地列表，V1 不分頁。

**NOTE**：同步狀態如何顯示（上次同步時間、同步中、有無新的一話、失敗）待討論（Q-F4）。

### F-11 同步詳情

**功能名稱**：向來源網站取得最新的漫畫詳情。

**邊界**
- 做：只同步詳情（封面、作者、狀態、地區、標籤、簡介、更新日期）。
- 不做：章節（見 [F-12](#f-12-同步章節)）、圖片。

**觸發**：使用者在漫畫詳情頁按「（遠端）同步詳情」。

**輸入**：漫畫識別。

**輸出**：最新的詳情，前端 Render 更新後的詳情。

**資料**：讀寫 [Manga](data.md#manga)。有人加入這部漫畫才寫入；沒有（例如從遠端搜尋進來、尚未加入）只回傳給前端顯示，不寫入。

**動作**
1. 使用者按同步詳情。
2. 後端向 plugin 取得詳情；已有人加入則更新 Manga。
3. 前端更新詳情。

**權限**：已登入。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 同步詳情 | 來源無法存取（被封鎖、Cloudflare、網站改版）或漫畫下架 | 來源端 | 與畫面元素綁在一起顯示 |
| 同步詳情 | 最短間隔內再次同步（C-4） | 使用者端 | 不重複向來源抓取，即時提示 |

**前後端分工**：前端觸發、顯示結果與錯誤；後端向 plugin 取資料、判斷是否寫入、控制最短間隔。

**規模**：受最短間隔限制。

**NOTE**：寫入的 Manga 全體共用，所有把這部漫畫放進書庫的使用者都會看到更新。

### F-12 同步章節

**功能名稱**：向來源網站取得章節列表。

**邊界**
- 做：只同步章節列表。
- 不做：載入圖片（圖片在點選章節閱讀時才載入）、詳情（見 [F-11](#f-11-同步詳情)）。

**觸發**：使用者在漫畫詳情頁按「（遠端）同步章節」。

**輸入**：漫畫識別；每次要求的章節數量（控制顆粒度，選填）。

**輸出**：章節列表。回應直接帶回列表，前端據此更新，不另外再打 API。

**資料**：讀寫 [Chapter](data.md#chapter)。同樣是有人加入才寫入。

**動作**
1. 使用者按同步章節。
2. 後端向 plugin 取得章節列表，與現有章節比對。
3. 沒有衝突：寫入（有人加入時）並回傳列表。
4. 有衝突（來源重新編號、刪除章節或換源，C-5）：不自動套用，回饋給前端由使用者決定。
5. 前端 Render 章節列表，或顯示衝突。

**權限**：已登入。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 同步章節 | 來源無法存取（被封鎖、Cloudflare、網站改版）或漫畫下架 | 來源端 | 與畫面元素綁在一起顯示 |
| 同步章節 | 發現與現有章節衝突（來源重新編號、刪除章節或換源，C-5） | 來源端 | 不自動套用，回饋給前端由使用者決定（Q-F7） |
| 同步章節 | 最短間隔內再次同步（C-4） | 使用者端 | 不重複向來源抓取，即時提示 |

**前後端分工**：前端觸發、顯示列表與衝突；後端向 plugin 取資料、比對、判斷是否寫入。

**規模**：對遠端的請求要控制顆粒度，不一次取大量章節；受最短間隔限制。

**NOTE**：衝突不存狀態，只是這次同步的結果。使用者可選的動作待定（Q-F7）。

## 6. 閱讀

### F-13 閱讀章節

**功能名稱**：閱讀一章的圖片。

**邊界**
- 做：手動捲動、手動翻頁，可互相切換（A-2）。
- 不做：圖片以外的內容。

**觸發**：使用者在詳情頁點擊章節。

**輸入**：章節識別（來源、漫畫 ID、章節 ID）；閱讀方式（捲動或翻頁）。

**輸出**：該章的圖片。

**資料**：讀 [章節圖片](data.md#章節圖片)。快取未命中時由後端請 plugin 抓取並寫入。

**動作**
1. 請求該章。
2. 後端確保圖片已在檔案系統：命中直接回傳，未命中請 plugin 抓取。
3. 前端顯示載入動畫並載入圖片。
4. 使用者以捲動或翻頁閱讀。

**權限**：已登入。未加入書庫的漫畫也可以閱讀；圖片寫入 `library` 或使用者私有的 `scratch`，由後端依 ref count 決定。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 載入章節 | 來源無法存取、圖片載入失敗 | 來源端 | 與畫面元素綁在一起顯示 |
| 載入章節 | 章節不存在 | 使用者端 | 顯示 404 頁面 |
| 載入章節（需要寫入圖片） | 圖片空間已達設定檔的上限，寫入失敗 | 伺服器 | 顯示通用的紅色提示 |

**前後端分工**：前端負責呈現與切換閱讀方式；後端負責快取、抓取、決定寫入位置。

**規模**：一章頁數不定。未命中時會對來源發請求（C-4）；同一章被多人同時請求時，由後端避免重複下載。

### F-14 切換章節

**功能名稱**：在閱讀器切換到上一話或下一話。

**邊界**
- 做：切到相鄰的章節。
- 不做：跳到任意章節（回詳情頁選擇）。

**觸發**：使用者點上一話、下一話。

**輸入**：目前的章節。

**輸出**：閱讀器頁面載入目標章節。

**資料**：以手上的章節列表算出目標章節，不需要額外的 API；目標章節的圖片同 [F-13](#f-13-閱讀章節)。

**動作**
1. 前端算出目標章節。
2. 觸發 [F-13](#f-13-閱讀章節)。

**權限**：同 [F-13](#f-13-閱讀章節)。

**失敗**

| 引起的操作 | 錯誤 | 類型 | 系統反應 |
| --- | --- | --- | --- |
| 切換章節 | 已是第一章或最新章節 | 使用者端 | 提示沒有上一話或下一話 |
| 切換章節 | 目標章節載入失敗 | 來源端 | 同 F-13 |

**前後端分工**：前端計算目標；後端同 [F-13](#f-13-閱讀章節)。

**規模**：目標章節尚未快取時會觸發 plugin 抓取。
