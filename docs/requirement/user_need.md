# Suwayomi 使用者需求（User Needs）

Sep 27, 2026 · @Bongo

# 背景

「接案社」是由東華資工系成立的接案子社團

導師希望成員們（包括我也是成員）可以練習如何從頭開始建立一個新的專案，並且和其他人協同開發。

Suwayomi 是 github 上有名的漫畫閱讀器，他基於前後端的架構 + 插件（plugin）的方式管理組成。

其中後端透過 plugin 取得並儲存漫畫資源，前端負責使用者互動介面，plugin 則是針對特定網站的網路爬蟲。

---

需要搞清楚我們希望這個「基於網頁前後端」的漫畫閱讀系統，要提供哪些功能？

# User Need

> UN 表示 User Need，每條依下列格式撰寫：
>
> - 作為一個：誰
> - 我希望：需求本身，不寫做法
> - 以便：動機或價值
> - 可能做法：候選方案，之後再討論取捨

## UN-1

作為一個：注重閱讀體驗的使用者

我希望：能依照自己的習慣和作品類型選擇閱讀方式

以便：條漫、日漫等不同排版的作品都能舒適閱讀

可能做法：

- 支援上下滑動閱讀
- 支援翻動閱讀
- 支援自動閱讀

## UN-2

作為一個：電腦用戶

我希望：可以善用滑鼠和鍵盤

以便：不用頻繁點擊畫面上的按鈕也能流暢操作

可能做法：支援常用快捷鍵（hot key）

## UN-3

作為一個：喜歡晚上熬夜看漫畫的讀者

我希望：晚上閱讀時畫面不會太刺眼

以便：長時間夜讀眼睛不容易疲勞

可能做法：提供護眼模式，可依需求選擇開啟或不開啟

## UN-4

作為一個：漫畫讀者

我希望：系統記住我讀到哪一話

以便：下次打開時可以直接接續

可能做法：標注我之前看到那一話

## UN-5

作為一個：追連載的讀者

我希望：有新的一話時系統能自己抓到

以便：不錯過更新，也不用逐部手動檢查

可能做法：可以手動更新或者背景自動更新漫畫

## UN-6

作為一個：會依環境調整介面的使用者

我希望：可以切換深色或淺色介面

以便：白天和晚上都能用舒服的介面

可能做法：提供深色／淺色主題切換

> 備註：UN-6 是可選需求

## UN-7

作為一個：等待漫畫載入的讀者

我希望：載入時知道系統正在處理

以便：不會誤以為當機而重複點擊或離開

可能做法：顯示載入動畫

## UN-8

作為一個：遇到系統錯誤的使用者

我希望：後端發生錯誤時（例如加載新的漫畫失敗），能在畫面上看到提示

以便：知道操作沒有成功，可以重試或改用其他方式

可能做法：在前端顯示紅色的錯誤提示

> 備註：UN-8 是潛在需求

## UN-9

作為一個：開到不存在頁面的使用者（例如網址打錯、漫畫已被移除）

我希望：知道這個頁面不存在

以便：不會面對空白畫面，並能回到主頁

可能做法：提供 404 頁面，附回到主頁的連結

> 備註：UN-9 是潛在需求

# 系統需求-V1

SR 依前端、後端、plugin 分類，每條標出來源（UN／C／A）與版本；V1 = 第一版要支援。

## Feature

- **多人帳號**：管理者發配帳號，每個人有自己的書庫、資料夾與閱讀紀錄
- **Plugin 來源**：每個來源網站一個 plugin，可安裝、更新、移除
- **搜尋**：搜尋自己的書庫，或勾選 plugin 搜尋來源網站並加入書庫
- **資料夾分類**：一部漫畫可以放進多個資料夾
- **閱讀**：手動捲動或翻頁、快捷鍵操作、暖色濾鏡
- **閱讀紀錄**：記住每部漫畫讀到哪一話
- **檢查更新**：排程與手動檢查新章節；會影響閱讀紀錄的更新交由使用者決定
- **圖片快取**：章節圖片存在伺服器，全體使用者共用

規劃中：自動閱讀、深色／淺色主題、手機版。

## 錯誤處理

依「錯在哪」分成三類，各自決定顯示方式。

| 類型 | 例子 | 顯示方式 |
| --- | --- | --- |
| 來源端 | 自動檢查更新失敗、被來源封鎖、網站改版（PL-07）、漫畫下架 | 與畫面元素綁在一起，類似新聞網站刷新失敗 |
| 使用者端 | 操作不合法、手動檢查更新太頻繁（C-4） | 即時回饋，形式看設計（例如彈跳視窗） |
| 伺服器 | 後端內部錯誤 | 回傳 5xx；前端顯示通用紅色提示（UN-8），後端記入 log（BE-16） |

| 按鍵 | 動作 | 頁面 |
| --- | --- | --- |
| ← / → | 上一頁 / 下一頁 | 閱讀頁 |
| ↑ / ↓ | 往上 / 往下捲動 | 閱讀頁 |
| Space / Shift+Space | 往下 / 往上一個畫面 | 閱讀頁 |
| \[ / \] | 上一話 / 下一話 | 閱讀頁 |
| A | 開始或暫停自動閱讀 | 閱讀頁 |
| M | 切換閱讀方式 | 閱讀頁 |
| F | 全螢幕 | 閱讀頁 |
| Esc | 離開閱讀頁，回到詳情頁 | 閱讀頁 |
| / | 聚焦搜尋框 | 全部 |
